# APB GPIO Controller Status Report

1. Project Name

APB GPIO Controller

2. Project Objective

The objective of this project is to design and verify an APB-based GPIO controller.

The controller allows software to control GPIO pins through memory-mapped registers. The design supports GPIO output control, direction configuration, interrupt generation, and APB error handling.

4. Verification Work Completed

A self-checking Verilog testbench has been developed.

The testbench includes:

* Clock generation
* Reset generation
* APB write task
* APB read task
* APB idle task
* Data comparison task
* Single-bit comparison task
* Pass counter
* Fail counter

6. Current Status

The RTL design and directed functional testbench have been completed.

The implemented design covers the main GPIO functionality, APB register access, GPIO control operations, interrupt handling, and APB error conditions.

The testbench provides automated checking using pass and fail counters.


7. Conclusion

The APB GPIO Controller project has successfully completed the RTL design and basic functional verification stages.

The project includes a parameterized APB GPIO controller and a self-checking Verilog testbench with twelve directed test cases. The design verifies GPIO data control, direction control, SET/CLR/TOGGLE operations, interrupt functionality, and APB error handling.
